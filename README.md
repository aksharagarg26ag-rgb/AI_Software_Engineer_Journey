# 🚀 How to Run

Clone Repository

```bash
git clone https://github.com/<your-username>/AI_Software_Engineer_Journey.git
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate

Windows

```bash
venv\Scripts\activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run Project

```bash
python app.py
```
